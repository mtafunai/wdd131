WDD 131 Project Website Plan

Website Planning Document

This document provides the plan for the Fiji Explorer website, including its purpose, target audience, visual design, typography, and home page wireframe.

1. Site Name

🌴 Fiji Explorer

The name Fiji Explorer was chosen because the website will help visitors discover destinations, attractions, activities, and experiences throughout Fiji. The name is simple, memorable, and clearly communicates the purpose of the website.

Optional domain: fijiexplorer.com

2. Site Purpose

The purpose of Fiji Explorer is to provide visitors with useful information about places and activities to explore in Fiji. The website will feature destination information, beaches, outdoor activities, cultural experiences, and other attractions.

Visitors will be able to explore different locations and learn about things they can see and do while visiting Fiji. The website will also provide a contact form for visitors who want to submit questions or request additional information.

3. Scenarios

The following questions represent information that members of the target audience may want to find when visiting the website:

  • What are some of the best places to visit in Fiji?
  • What activities can I do while visiting Fiji?
  • Which beaches and islands should I explore?
  • Where can I find information about different destinations in Fiji?

4. Color Scheme

The color scheme is inspired by Fiji's tropical environment, ocean, beaches, and natural landscape.

#0077B6

Ocean Blue

Used for the header, navigation, main headings, buttons, links, and important accents.

#2A9D8F

Tropical Green

Used for secondary accents, interactive elements, borders, and highlighted information.

#F4E9D8

Sand

Used as the main background color and for content cards and information sections.

#FFFFFF

White

Used for text on darker backgrounds and for contrast in navigation and buttons.

5. Typography

Playfair Display

Used for: Site title, main headings, and major section headings.

Montserrat

Used for: Body text, navigation links, buttons, forms, descriptions, and general content.
